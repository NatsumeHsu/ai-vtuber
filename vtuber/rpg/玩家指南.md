# RPG 玩家指南

這是一套 Twitch／Discord 共用的冒險 RPG。你可以打怪升級、蒐集裝備、培養夥伴，也能靠採集、派遣與聚落慢慢累積資源。

這份指南只介紹遊戲玩法。以下保留英文指令，方便直接輸入；Discord 的繁中指令選單也會顯示對應中文名稱。Twitch 範例使用預設前綴 `!`。

## 1. 第一次玩，從這裡開始

1. 在 Discord 使用 `/rpg register`，填入角色名稱；想自己選外觀與信念，則使用原生 `/register`，跟著畫面完成登記。兩種方式擇一即可。
2. 登記完成會有 **200 金幣**。接著開啟 `/journey`，按下領取獎勵，拿到 1 級的新手武器與 **20 瓶藥水**。
3. 開啟 `/inventory`，把剛領到的武器裝上。領到背包裡，不等於已經裝備。
4. 使用 `/quests`，先選好自己做得到的委託，再去打怪，這樣戰鬥也能順便推進任務。
5. 使用 `/combat` 進入互動戰鬥，或用 `/rpg combat` 進行一次自動戰鬥。
6. 升級後若出現配點選項，先選好能力。共用指令可以用 `/rpg package` 查看，再選 1、2 或 3。
7. 達到 5 級後，再開一次 `/journey`，領取 **10,000 金幣與 2 個奇物**。

如果打得很吃力，先確認武器有沒有裝上、升級配點有沒有選完，再考慮花錢強化。

## 2. 我要怎麼賺錢？

### 新手優先做：任務、打怪、領旅程獎勵

| 方式 | 怎麼操作 | 能拿到什麼 | 注意事項 |
|---|---|---|---|
| 戰鬥 | Discord `/combat` 或 `/rpg combat`；Twitch `!rpg combat` | 獲勝後取得金幣、經驗，並有機會掉裝備與材料 | 金額會隨敵人、裝備效果、難度與連勝等條件改變，不是每場固定金額 |
| 每日委託 | Discord `/quests`，接任務、完成後回來交付 | 普通委託基礎 **25,000 金幣**；三星委託基礎 **75,000 金幣**，另有任務代幣 | 一般每日最多接 3 份；部分升級能改變額度或獎勵。先看目標，別只挑獎勵最高的 |
| 旅程里程碑 | Discord `/journey`，達到等級後按領取 | 指定節點提供大量金幣，也有武器、藥水、招募券與材料 | 每個節點只能領一次，需要自己領取 |
| 夥伴戰鬥派遣 | 10 級後使用 Discord `/partner`，招募夥伴並安排戰鬥派遣 | 金幣、夥伴經驗，並可能帶回鑰匙或符文 | 先派出去，累積時間後再收取；採集派遣主要提供材料，不等同戰鬥派遣 |
| 玩家交易 | Discord `/trade` | 與其他玩家交換裝備、資源及金幣 | 須有人願意交易，價格由雙方決定 |
| 幽界市集 | Discord `/nether` | 買低賣高，或嘗試掠奪其他藏品 | 有行情與失敗風險，不是穩定收入 |

**任務加成：**任務商店的「Enrichment」升級能讓交付任務的金幣增加 50%；對應基礎獎勵會變成 37,500 或 112,500 金幣。取得條件與代幣花費可在任務商店查看。

### 旅程裡，哪些節點會送錢？

| 達到等級 | 該節點金幣獎勵 |
|---|---:|
| 5 | 10,000 |
| 20 | 50,000 |
| 30 | 100,000 |
| 40 | 150,000 |
| 50 | 200,000 |
| 70 | 500,000 |
| 90 | 500,000 |

這些是一次性的里程碑獎勵，不是每天可領的收入。其他等級節點也有獎勵，只是不一定是金幣。

### 掛機、簽到和賭博呢？

**夥伴派遣**是主要的時間累積玩法之一。一般派遣收益最多累積 48 小時，部分夥伴效果能延長；不要忘記回來收取。戰鬥派遣的收益還會受到角色等級與夥伴技能影響。

**採集**主要累積強化所需的材料，能省下發展成本，但不是站著每分鐘固定領金幣。

**簽到**在 10 級開放，領取間隔為 18 小時，使用 14 日循環獎勵。主要提供奇物、招募券、任務代幣與各類材料，不是固定發錢。

**賭博**會輸錢。剛起步時，先把金幣留給必要的藥水、工具與裝備，別把它當作主要賺錢方法。

## 3. 金幣怎麼花比較划算？

新手可以依這個順序安排：

1. 先領 `/journey` 的免費裝備與藥水，避免重複購買起步用品。
2. 把能提升生存與勝率的裝備穿上，並完成待選的升級配點。
3. 依需要補藥水，不必每次都把錢花光。商店的「補滿」只購買缺少的數量。
4. 替準備持續使用的裝備做適度強化；很快就會換掉的裝備，可以先少投資一些。
5. 想長期累積資源，再逐步升級採集工具與安排派遣。

榮耀外觀、改名和高風險強化都可以晚點再碰，先讓自己的冒險循環順起來。

## 4. 戰鬥怎麼玩？

### Discord 互動戰鬥：`/combat`

進入畫面後，先看敵人能力與特殊效果，再決定操作。

| 操作 | 效果 |
|---|---|
| 攻擊 | 進行一回合攻擊；敵人還活著時通常會反擊 |
| 喝藥水 | 消耗藥水回復生命，也會花掉一回合 |
| 撤退 | 結束這場遭遇，避免繼續硬打 |
| 自動戰鬥 | 讓戰鬥自動推進；仍需留意敵我狀態 |
| 進行 10 回合 | 快速推進一段戰鬥 |
| 一路打到底 | 快速持續戰鬥，風險也比較高 |

原生戰鬥還可能遇到首領入口與特殊遭遇，跟著畫面做選擇即可。

### 共用自動戰鬥：`/rpg combat`、`!rpg combat`

一次指令會自動完成一場一般遭遇，最多推進 600 回合，再回覆勝負、金幣、經驗與剩餘生命。這種方式適合簡單刷怪，不會提供原生 `/combat` 的首領入口選擇。

### 體力、生命與落敗

- 一般戰鬥會消耗 1 點體力，部分能力有機會節省消耗。
- 常態體力上限為 10，低於上限時按每小時恢復 1 點的機制補充；特殊效果可能改變恢復或讓體力超過常態上限。
- 生命與體力是不同數值。生命不足時，就算有體力，也不適合繼續打。
- 普通模式落敗通常損失目前等級經驗的 10%，部分保護效果能減免；高難度可能清空目前等級的經驗。
- 落敗會中斷連勝。先挑穩定打得贏的難度，再追求額外收益。

## 5. 升級與角色能力

使用 `/rpg profile` 看簡短狀態，或用 `/stats`、`/passives` 查看完整能力與被動效果。

升級後可能要選擇一組能力方案。共用指令是：

```text
Discord：/rpg package
Twitch：!rpg package
```

看完三組方案後，選擇 1、2 或 3。Twitch 範例：`!rpg package 1`。

攻擊、防禦與生命要一起考慮。只堆攻擊，可能還沒打倒敵人就先倒下；也別忘了裝備與被動效果會改變實際表現。

`/allocate_stats` 管理的是另外取得的能力點數，與升級時選三組方案不同。

## 6. 裝備與強化

| 想做的事 | Discord 指令 |
|---|---|
| 查看與管理裝備 | `/inventory`、`/gear` |
| 只看某一部位 | `/weapons`、`/armor`、`/accessory`、`/gloves`、`/boots`、`/helmets` |
| 儲存及切換整套配裝 | `/loadouts` |
| 查看背包數量摘要 | `/rpg inventory`；Twitch `!rpg inventory` |

拿到裝備後，先比較能力、品質與被動，再決定是否換上。高等級不一定就適合目前的配裝。

強化操作從裝備介面進入：武器有鍛造、精煉等方式；護甲等部位也有淬鍊、加固、注魔等操作。各自需要的金幣、材料、次數和成功率不同，確認畫面會列出條件。

虛空鍛造會消耗祭品武器，無論成功與否祭品都會消失。每次結果為成功 25%、混沌 25%、失敗 50%；混沌可能覆蓋主要被動。這不是新手必做的強化。

## 7. 回血、藥水與休息

- `/shop`：買藥水。一般最多攜帶 20 瓶，價格與效果會隨等級變化。
- `/rest`：在酒館回滿生命。免費休息的冷卻為 2 小時；冷卻中再次休息，可能需要付費。
- `/player_settings`：可調整自動支付休息費等偏好。開啟自動支付後，符合條件時會直接扣款。

想省錢，就留意免費休息時間。酒館回滿生命，不等於同時補滿戰鬥體力。

## 8. 任務、旅程與每日獎勵

**每日委託 `/quests`：**先接任務，再做對應的活動，完成後回任務板交付。任務代幣可在任務商店換物資或購買升級。重抽委託也會花代幣，別為了追求完美任務一直重抽。

**遠景之路：**同樣在任務系統內，是長期目標。選擇符合目前玩法的路，讓平常的冒險順便推進。換路會重設進度，決定前先看清楚。

**旅程 `/journey`：**查看等級里程碑與領取獎勵。它不是每日重置的任務，也不會因升級就自動把所有獎勵送進背包。

**簽到 `/checkin`：**10 級開放，每 18 小時可領下一次循環獎勵。

**獵魔委託 `/slayer`：**接指定物種的狩獵目標，再透過戰鬥完成，累積獵魔經驗、徽章與相關獎勵。

| 夥伴 | `/partner` | 10 級開放，使用招募券招募，安排出戰或派遣，培養技能與好感度 |

採集、派遣與聚落的收益方式各有不同，不是打開任何一個選單就開始自動發金幣。先確認已安排好工作，再按各自畫面收取或推進。

## 12. Twitch 和 Discord 怎麼共用角色？

想兩邊一起玩，建議先在 Discord 建立角色，再做綁定：

1. Discord 使用 `/rpg link`，取得只顯示給自己的綁定碼。
2. 用自己的 Twitch 帳號在聊天輸入 `!rpg link 綁定碼`。
3. 成功後，兩邊使用同一角色、金幣、經驗與背包。綁定碼預設五分鐘內有效，只能使用一次。

尚未綁定前，兩邊的角色是獨立的。相同暱稱不會自動合併；若 Twitch 已經建立角色，就不能直接覆蓋或把資產自動合到 Discord。

| Twitch 目前可用 | Discord 對應 |
|---|---|
| `!rpg help` | `/rpg help` |
| `!rpg register 名稱` | `/rpg register` |
| `!rpg profile` | `/rpg profile` |
| `!rpg inventory` | `/rpg inventory` |
| `!rpg combat` | `/rpg combat` |
| `!rpg package`、`!rpg package 1` | `/rpg package` |
| `!rpg link 綁定碼` | `/rpg link` 取得碼 |

完整裝備管理、任務、領取旅程獎勵、派遣與進階互動，請到 Discord 操作。目前沒有 `!rpg rest`、`!rpg journey`、`!rpg quests` 或掛機領錢用的 `!rpg claim`。

同一角色在 Discord 開著互動視窗時，Twitch 可能會提示「正在進行其他 RPG 操作」。先完成或關閉該視窗，再繼續即可。

## 13. 每次上線，照這個順序就好

1. 看角色狀態，確認生命、體力與待選的升級配點。
2. 到 `/journey` 領取新達成的里程碑獎勵。
3. 10 級後看看 `/checkin` 能不能領取下一次獎勵。
4. 到 `/quests` 接適合今天玩法的委託。
5. 收取派遣、檢查採集與聚落進度，再安排接下來的工作。
6. 整理裝備，開始戰鬥，順便推進任務或獵魔委託。
7. 缺血就看免費休息是否可用，不必為了多打一場把錢全花掉。
8. 結束前交付完成的任務，收好獎勵，安排派遣。

## 14. 常見問題

**我剛加入，很窮怎麼辦？**

先領 `/journey` 的 1 級武器和藥水，裝備好，再接委託去打怪。升到 5 級後回來領 10,000 金幣。先把這個循環做好，不必急著賭博或挑戰高難度。

**打怪賺得不多，是正常的嗎？**

前期單場戰鬥的收入通常不如里程碑與任務明顯。把任務、打怪、升級與領旅程獎勵一起做，會比較有感。

**升級了，卻不能繼續自動戰鬥？**

先用 `/rpg package` 或 `!rpg package` 選完待處理的能力方案。

**有體力，為什麼還是不能打？**

可能是生命太低、還有配點沒選，或同一角色正開著其他 RPG 操作。依提示先處理即可。

**簽到為什麼不能用？**

先確認達到 10 級，以及距離上次領取是否滿 18 小時。

**為什麼沒有自動收到等級獎勵？**

旅程獎勵要到 `/journey` 手動領取。新手武器領到後，也要自己裝上。

**我能把 Twitch 和 Discord 已有的兩個角色合併嗎？**

目前沒有自動合併功能，也不會直接覆蓋既有角色。想共用角色，請在 Twitch 尚未建角時先完成綁定。

**中文版指令名稱和指南不一樣？**

指南使用保留的英文指令名稱，便於輸入和查找。Discord 繁中介面可能顯示「戰鬥」「冒險」「背包」等中文選項，選擇對應玩法即可。
